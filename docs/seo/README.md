# SEO Execution Pack (Q1 2026)

## Goal
Turn existing platform features into search-visible assets with conversion intent.

## Weekly Loop
1. Publish 2 blog posts linked to one service page and one portfolio case.
2. Publish 1 portfolio case page with real photos and event metrics.
3. Update 1 money page (`/servicios/*`) with fresh internal links + FAQ.
4. Review Search Console winners/losers and adjust titles + intros.

## Mandatory Content Inputs Per Case
- Real event date and city.
- Pack + extras used.
- Guest range.
- Setup duration and event duration.
- Client goal and achieved result.
- 3 to 8 original photos.

## KPI Targets
- +25% non-brand clicks in 90 days.
- +15% lead form starts from organic.
- Portfolio pages in top 20 for 5 transactional long-tail queries.

## Ownership
- Ops: gathers event assets (photos, facts, approvals).
- Marketing: writes draft using template and links map.
- Tech: publishes and validates schema + Core Web Vitals.
