Política de privacitat OAuth de Google

Última actualització: 17 de febrer de 2026

Aquesta política explica com Orbita Events accedeix, utilitza, emmagatzema i comparteix dades d'usuari de Google quan un administrador connecta integracions OAuth a orbitaevents.com.

Aquesta pàgina complementa la política general: https://orbitaevents.com/legal/privacidad.

1. Dades a les quals accedim (Data Accessed)

Només accedim a les dades necessàries per a les funcionalitats activades per l'usuari administrador:

  • Google Business Profile (https://www.googleapis.com/auth/business.manage): comptes i localitzacions de negoci per configurar integracions de ressenyes i perfil.
  • Gmail (https://www.googleapis.com/auth/gmail.readonly, https://www.googleapis.com/auth/gmail.modify): metadades i contingut de correus per gestionar inbox comercial intern (lectura, classificació i estat).
  • Google Calendar (https://www.googleapis.com/auth/calendar.events, https://www.googleapis.com/auth/calendar.readonly): llistat de calendaris i esdeveniments necessaris per sincronitzar reserves.
  • Identificació bàsica de compte connectat: adreça de correu del compte i identificadors tècnics de calendari/compte per mantenir la connexió.

2. Com utilitzem les dades (Data Usage)

  • Configurar i mantenir connexions OAuth iniciades per l'administrador.
  • Mostrar i operar la safata comercial interna (Gmail) dins del panell d'administració.
  • Sincronitzar reserves i disponibilitat amb Google Calendar.
  • Configurar la integració de Google Business Profile per funcionalitats internes de negoci.
  • Monitoritzar estat tècnic de connexions (data de connexió, compte vinculat, errors d'integració).

No utilitzem dades de Google per publicitat.

No venem dades de Google a tercers.

No utilitzem dades de Google per entrenar models d'IA/ML generalistes.

3. Emmagatzematge i seguretat (Storage & Security)

  • Els refresh tokens i metadades d'integració es guarden al backend segur de l'aplicació.
  • Els access tokens s'utilitzen de forma temporal per fer crides API i no es publiquen al client.
  • L'accés al panell administratiu està restringit per autenticació d'admin.
  • Les comunicacions amb Google API es fan per HTTPS.

4. Compartició de dades (Data Sharing)

Orbita Events no comparteix dades de Google amb tercers, excepte:

  • Proveïdors d'infraestructura necessaris per allotjar i operar l'aplicació (hosting i base de dades).
  • Requeriments legals o ordres vàlides d'autoritat competent.

5. Retenció i eliminació (Retention & Deletion)

  • Les dades OAuth es mantenen mentre la integració estigui activa o sigui necessària per prestar el servei.
  • L'administrador pot desconnectar la integració i sol·licitar eliminació de credencials associades.
  • Per sol·licituds d'accés, rectificació o supressió: info@orbitaevents.com.

6. Compliment de polítiques Google

L'ús de dades obtingudes via Google API compleix la Google API Services User Data Policy, inclosos els requisits d'Limited Use, i els termes aplicables de Google APIs.

7. Contacte

Responsable: Orbita Events
Correu: info@orbitaevents.com
Web: https://orbitaevents.com
